### 🚀 What I care about

- **Clean architecture** — service layer for business logic, thin views, selectors/repositories for data access.
- **Solid data modelling** — proper normalization, indexes, FK &amp; unique constraints, and killing N+1 queries with `select_related`/`prefetch_related`.
- **Event-driven, DDD-lite thinking** — domain events (`PolicyIssued`, `InvoiceGenerated`) to decouple side effects from core logic.
